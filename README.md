# Cubieboard 1 Autonomous Wi-Fi Router
Власний `.deb` пакет для швидкого розгортання Wi-Fi точки доступу з паролем (12345678) WPA2 та підтримкою Hot Plug USB (для ядра 6.12.103-legacy-sunxi) для USB Wi-Fi адаптера Realtek RTL8188EUS.

## 🚀 Встановлення:

Введіть ці команди в консоль вашого Cubieboard:

```bash
wget https://raw.githubusercontent.com/mcvladoc33/cubie-router/main/cubie-router.deb

sudo apt install ./cubie-router.deb

rm cubie-router.deb
```
