# Cubieboard 1 Autonomous Wi-Fi Router
Власний `.deb` пакет для швидкого розгортання прихованої Wi-Fi точки доступу з паролем WPA2 та підтримкою Hot Plug USB (для ядра 6.12.103-legacy-sunxi).

## 🚀 Встановлення в одну команду:

Введіть цю команду в консоль вашого Cubieboard (перед запуском видаліть пробіли з посилання, щоб воно стало суцільним):

wget https://raw.githubusercontent.com/mcvladoc33/cubie-router/main/cubie-router.deb && sudo apt install ./cubie-router.deb && rm cubie-router.deb
