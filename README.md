\# Cubieboard 1 Autonomus Wi-Fi Router

Власний `.deb` пакет для швидкого розгортання прихованої Wi-Fi точки доступу з паролем WPA2 та підтримкою Hot Plug USB (для ядра 6.12.103-legacy-sunxi).



\## 🚀 Встановлення в одну команду:

```bash

wget https://githubusercontent.com \&\& sudo apt install ./cubie-router.deb \&\& rm cubie-router.deb

```
